Multi-machine Julia over SSH

DistSSHKit

Run Julia on SSH machines from your laptop, including Distributed drive workers. Or submit to a queue on an always-on host and fetch results after you disconnect.

Requirements First queue job User Guide

Run from this machine

Start go or drive from your laptop; SSH stays up until the run finishes and workers join over the network.

Prepare SSH hosts

Deploy your project to each machine and match Julia channels before you run or queue.

Queue on an always-on host

Submit from your laptop; jobs run on the queue host one at a time while you disconnect and collect results later.

Install

Julia 1.13+ on macOS, Linux, and WSL2 Ubuntu (not native Windows).

pkg> add DistSSHKit

You still need ssh, rsync, and git (git deploy only) on the machines involved. See Requirements.

What you can do

One julia -m DistSSHKit install covers host prep, runs you start on this machine, and client commands that talk to a queue host.

Run (interactive). From your laptop or login node, go runs a script on listed SSH slots; drive keeps a master process here and adds Distributed workers on parent and remote hosts while you stay connected. See User Guide for ride, pool, and the rest.

Queue (away from keyboard). On a machine that stays powered on, qhost setup turns it into a queue that accepts jobs. From your job project on the laptop you submit, check status, and fetch output when you are back (First job, How it runs).

Host prep is shared: run setup and up once per cluster before either style.

How it works

  1. Prepare hosts. setup and up put your project and the same Julia channel on each SSH machine (Prepare).
  2. Run now (optional). While connected, start a run from this machine—for example julia -m DistSSHKit go child:host:1 SCRIPT.jl or a drive script with workers (go).
  3. Or use the queue. On the always-on host, run qhost setup (Prepare the machine). From the laptop, submit the same kinds of jobs (go, ride, drive) to that host; they execute there after you disconnect.

Example run from this machine:

julia --project=. -m DistSSHKit go parent:1 child:user@host:2 SCRIPT.jl

Example queue client from a job project:

julia --project=. -m DistSSHKit qhost:HOST submit go parent:1 SCRIPT.jl
julia --project=. -m DistSSHKit qhost:HOST status
julia --project=. -m DistSSHKit qhost:HOST fetch <id>

Embedders who install DistSSHRun or DistSSHQueue without Kit: Package split.
