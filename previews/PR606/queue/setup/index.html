setup

Write config, or wipe Queue state on this host.

julia -m DistSSHKit qhost setup [--force]
julia -m DistSSHKit qhost up
julia -m DistSSHKit qhost up update
julia -m DistSSHKit teardown

Also: Prepare, Walkthrough, serve, hosts. setup refuses qhost:. teardown without --confirm-path or -y prints Would remove (exit 0) and does not delete. Pass --confirm-path once for each listed path to wipe. -y / --yes and DISTSSHKIT_YES (process or config [env]) still delete. That stops in DistSSHKit 0.11 (DistSSHQueue 0.10). From a client, pass qhost:HOST teardown --confirm-path '~/path'. Quote the path so the local shell does not expand ~.

setup is optional. Defaults work without config.toml. Re-run is a no-op unless --force. It writes config.toml only, not ~/.distsshqueue/env.

-h / --helpQueue usage

DISTSSHQUEUE_YES is gone. [env] in the target config.toml still applies.

teardown

Stops serve, removes the OS unit and ~/.distsshqueue. Does not Pkg.rm, and never deletes a git clone or .distsshkit/ results. Trees: Where files live. Still removes leftover ~/.distsshkitqueue, old org.distsshkitqueue.serve units, and ~/.local/bin/dskq if present.

config.toml

~/.distsshqueue/config.toml. Override: DISTSSHQUEUE_CONFIG. Resolution: CLI / ENV > config.toml > built-in defaults. [env] keys use get! so a real ENV value wins.

store = "~/.distsshqueue/jobs.toml"
# hosts = ["parent", "child:host1:4"]

[env]
# DISTRIBUTED_SSH_OPTS = "-F /path/to/ssh_config"
# DISTSSHKIT_YES = "1"  # up default, and teardown until DistSSHKit 0.11.
# Do not set DISTRIBUTED_REMOTE_PROJECT_ROOT here on a shared queue host.
KeyMeaning
storeJob table path (DISTSSHQUEUE_STORE)
hostshost tokens; missing = CLI needs add-host before a named token; [] = allow none
[env]Default ENV for this host (not DISTSSHQUEUE_HOST). Skip DISTRIBUTED_REMOTE_PROJECT_ROOT unless this box is one job
